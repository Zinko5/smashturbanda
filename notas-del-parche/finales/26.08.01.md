## [26.08.01.01] - Miniparche de Desarrollo

### 1. Nuevas características o funciones
* **Robustez en Validación de Versiones**: Se mejoró el controlador `version_check` para retrasar la desconexión 3.5 segundos en caso de incompatibilidad, permitiendo que los usuarios visualicen el aviso informativo de versión. Asimismo, se implementó un refrescado forzado (`window.location.reload(true)`) en ambos extremos (host y guest) para limpiar automáticamente cachés persistentes del navegador.

### 2. Correcciones de bugs antiguos
* **Desincronización de Versión en multiplayer.js**: Se corrigió el bug que congelaba la constante interna `GAME_VERSION` en la versión anterior (`26.07.06.12`) mientras el archivo HTML mostraba la `.13`. Este mismatch provocaba desconexiones silenciosas inmediatas en la fase de emparejamiento.

## [26.08.01.02] - Miniparche de Desarrollo

### 1. Nuevas características o funciones
* **Reintegración de Servidores TURN por Defecto (Open Relay)**: Se reactivaron los servidores TURN gratuitos de Open Relay (metered.ca) como relevo predeterminado para la conexión P2P. Cada URL se configura como un objeto ICE individual (formato compatible con PeerJS 1.4.7) en múltiples puertos y protocolos (UDP/80, TCP/443, TLS/443). Esto provee conectividad de respaldo cuando el P2P directo (STUN) falla por NAT simétrica, CGNAT o datos móviles.
* **Soporte de API Key de Metered.ca**: Se añadió un campo de API Key en el panel de Opciones que permite obtener credenciales TURN dinámicas directamente de Metered.ca. Si se configura una API Key válida, las credenciales dinámicas reemplazan al Open Relay estático.
* **Reorganización del Panel TURN en Opciones**: Se reorganizó la sección de configuración TURN para mostrar claramente la nueva opción de API Key de Metered y el servidor TURN personalizado como opciones complementarias.

### 2. Correcciones de bugs antiguos
* **Conexión WebRTC Fallida (ICE Failed) entre Redes Distintas**: Resuelto el fallo de conexión entre dispositivos en redes diferentes (ej. WiFi ↔ datos móviles) que fallaban con error `ICE failed` al no existir servidores TURN de respaldo. La causa raíz era que en el parche `26.07.06.12` se habían eliminado los servidores TURN por problemas de formato de URLs, dejando el juego sin capacidad de relevo.
