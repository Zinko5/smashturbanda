## [26.08.01.01] - Miniparche de Desarrollo

### 1. Nuevas características o funciones
* **Robustez en Validación de Versiones**: Se mejoró el controlador `version_check` para retrasar la desconexión 3.5 segundos en caso de incompatibilidad, permitiendo que los usuarios visualicen el aviso informativo de versión. Asimismo, se implementó un refrescado forzado (`window.location.reload(true)`) en ambos extremos (host y guest) para limpiar automáticamente cachés persistentes del navegador.

### 2. Correcciones de bugs antiguos
* **Desincronización de Versión en multiplayer.js**: Se corrigió el bug que congelaba la constante interna `GAME_VERSION` en la versión anterior provocando desconexiones silenciosas inmediatas en la fase de emparejamiento.

## [26.08.01.04] - Miniparche de Desarrollo

### 1. Nuevas características o funciones
* **Soporte de API Key Segura para TURN**: Se implementó la constante `TURN_BACKEND_URL` en `multiplayer.js` para conectar con un proxy serverless en Cloudflare Workers que oculta la API Key de Metered y distribuye credenciales dinámicas de TURN a los jugadores.
* **Limpieza de UI de TURN**: Se removió el campo de API Key del menú Opciones, dejando solo la configuración avanzada de TURN personalizado para usuarios con servidores propios.

### 2. Correcciones de bugs antiguos
* **Conexión WebRTC Fallida (ICE Failed) entre Redes Distintas**: Resuelto el fallo de conexión entre dispositivos en redes diferentes (ej. WiFi ↔ datos móviles) al reincorporar soporte de servidores TURN de respaldo.

## [26.08.01.06] - Miniparche de Desarrollo

### 1. Nuevas características o funciones
* **Proxy de Cloudflare Definitivo**: Se reestructuró el Worker de Cloudflare para utilizar una `API Key` permanente mediante petición `GET` a Metered.ca, evitando bloqueos por límite de peticiones (Rate Limit 429/500).
* **Fallback a OpenRelay**: Se re-inyectó el servidor gratuito `openrelay.metered.ca` como línea de defensa adicional en los `iceServers`.

### 2. Correcciones de bugs antiguos
* **Diagnóstico de Bloqueo de Red (ISP)**: Se documentó exhaustivamente que el fallo silencioso de conexión en redes móviles es causado por bloqueos de puertos UDP y DPI de las operadoras, recomendando redes Wi-Fi residenciales o uso de VPN.

### 3. Correcciones de bugs que vinieron con las nuevas características
* **Procesamiento de ICE Servers**: El parsing del JSON devuelto por Metered en `multiplayer.js` se refinó para extraer todas las URLs proporcionadas (UDP, TCP, TLS en los puertos 80, 443, 3478).
