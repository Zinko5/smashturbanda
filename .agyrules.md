# Project Intelligence (.agyrules)

## Core Guidelines
- **Git Restrictions**: If you are an AI, do **not** run git commands (e.g. `git add`, `git commit`, `git tag`, `git push`). These are explicitly reserved for human developers.
- **Versioning Standard**:
  - Format: `aa.bb.cc.dd` (Year.Month.AccumulatedPatch.DevelopmentMinipatch).
  - Version indicator in [index.html](file:///home/zinko/publico/smashturbanda/index.html) (bottom-right label) must be updated in sync with any updates or patches.
  - **Month Verification**: Always check the current system month when starting a new patch cycle. The `bb` portion must reflect the current calendar month (e.g., `08` for August), resetting the patch count `cc` to `01` if transitioning to a new month.
  - **Release Status Verification**: Check the corresponding poster file (`notas-del-parche/promocion/aa.bb.cc.typ`). If it already covers the latest minipatch changes, the patch is considered closed/released, indicating that subsequent changes must initiate a new patch cycle (e.g., `aa.bb.(cc+1).01`). Otherwise, continue under the current patch cycle as a minipatch.
- **Documentation workflow**:
  - Document all developmental miniparches inside the latest final patch file (e.g., [26.07.06.md](file:///home/zinko/publico/smashturbanda/notas-del-parche/finales/26.07.06.md)).
  - Accumulate list of features, old bug fixes, and regression bug fixes.

## Architectural Patterns
- Maintain clean, dependency-free JavaScript. Keep rendering decoupled from heavy frameworks.
- Optimize payloads over WebRTC. Always use array-based tuples/serialization mechanisms for network data rather than raw JSON objects.
- Ensure Gamepad input handles fallback seamlessly and integrates with Keyboard layout listeners via OR logic.
- **Networking/P2P Realities**: When debugging WebRTC `ICE failed` or infinite "conectando..." states, do not assume a code bug if standard STUN/TURN (Metered.ca/Google) are properly configured. Cross-device testing has proven that mobile carriers in the user's region deploy aggressive Symmetric NAT and Deep Packet Inspection (DPI) that severs WebRTC handshakes over both UDP and standard TCP/TLS ports. Furthermore, many enterprise/public Wi-Fi routers deploy "AP Isolation", physically blocking local mDNS/IP connections. Do not attempt to fix these ISP/Hardware blocks via JavaScript; advise the user to test over standard residential broadband or VPNs.
